# TECHMO Website — Project Instructions

## Project Overview

- TECHMO — Sri Lankan engineering, construction and steel building solutions company.

## Current Phase

- Design prototype only.
- No final project photographs yet.

## Stack

- Astro, TypeScript, static HTML, CSS, SVG.
- Minimal JavaScript; GSAP only when required.
- No backend, database or authentication.
- GitHub + Cloudflare Pages hosting.

## Design

- Premium creative industrial engineering website.
- Orange, black and white brand identity.
- Fixed Crane Scroll Experience.
- Hook lifts containers on scroll.
- Container doors reveal HTML service content.
- Use placeholders until real photos are supplied.
- Responsive and reduced-motion friendly.

## Performance

- Prioritize Core Web Vitals and fast loading.
- Use lightweight SVG and CSS.
- Minimize JavaScript and external dependencies.
- Optimize images and fonts.
- Avoid layout shifts and excessive animations.
- Clean up animation instances and listeners.

## SEO

- Semantic crawlable HTML.
- Unique service and project URLs.
- Metadata, canonical tags, sitemap.
- Verified structured business data only.
- Accessible links and image descriptions.
- Content works without animation.
- Never invent business facts.

## Security

- No credentials or secrets in source code.
- No unsafe HTML injection.
- Minimize third-party scripts.
- HTTPS and appropriate security headers.
- Maintain and audit dependencies.
- Protect confidential business information.

## Accessibility

- Keyboard navigation, visible focus.
- WCAG-conscious contrast and semantic markup.
- Respect `prefers-reduced-motion`.

## Code Quality

- Small focused components and functions.
- Separate layout, animations, styles and data.
- Reusable components and TypeScript.
- Avoid unnecessary frameworks and hydration.

## Workflow

- One approved step at a time.
- Explain intended changes first.
- Preserve existing files where possible.
- Test each implemented feature.
- Never deploy without approval.

## Communication Rules

- Communicate with the user in Sinhala (සිංහල).
- All explanations, progress updates, questions, error explanations and summaries must be in Sinhala.
- Keep code, file names, folder paths, commands, variables and technical terms in English.
- Explain technical concepts in simple Sinhala.
- Before making changes, explain the plan in Sinhala.
- Work one step at a time.
- Stop after each step and wait for user approval.
- Do not change existing project requirements.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
